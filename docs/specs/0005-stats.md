# 予約者ごとの合計時間

## 目的

誰がどれだけ部屋を押さえているかを確かめたい。

## ふるまい

- `booking stats` で、予約者ごとの合計時間を1行ずつ出す。
- 対象は、これから始まる予約だけ。開始が現在ちょうどの予約は含め、すでに始まっている予約は含めない。
- 並びは合計時間の多い順。同じなら名前の昇順。
- 1行は `miruky 3.5h` の形。15分単位なので小数第2位まで出し、末尾の0は1桁まで削る（`0.75h`、`1.0h`）。
- 対象の予約がないときは、何も出さない。

## 完了の条件

- 集計は service にあり、`cli.py` は表示だけを行う。
- 実行する日時やタイムゾーンで、テストの結果が変わらない。
- `make check` が通る。

## 扱わないこと

- 部屋ごとの集計
