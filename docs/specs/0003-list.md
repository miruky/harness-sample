# 予約の一覧

## 目的

どの部屋がいつ押さえられているかを確かめたい。

## ふるまい

- `booking list` で、予約を開始の早い順に1行ずつ出す。
- 1行は、予約ID、部屋、開始と終了（東京時間）、予約者の順。
- `--room` を付けると、その部屋だけを出す。
- `--date YYYY-MM-DD` を付けると、東京時間でその日に始まる予約だけを出す。日付をまたぐ予約は、始まった日に数える。
- `--room` と `--date` は同時に指定できる。
- 当てはまる予約がないときは、何も出さずに終了コード0で終わる。

## 完了の条件

- 実在しない日付や形式の違う日付は、終了コード1で理由を標準エラーに出す。
- UTCなど別のタイムゾーンで保存された予約も、東京時間の日付で絞れる。
- `make check` が通る。

## 扱わないこと

- 期間での絞り込み
