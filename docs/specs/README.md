# 仕様

機能の仕様を、実装より先に1件1ファイルで書きます。ここが元で、Confluence のページは写しです。

- ファイル名は `番号-短い名前.md`。1行目の `# 見出し` が Confluence のページの題名になる。
- 「完了の条件」は、確かめられる文で書く。テストは、この条件と1対1で対応させる。
- 仕様を変えるときは、同じプルリクエストでコードとテストも直す。
- Confluence の画面では編集しない。書き込みと一致の確認は、`/sync-specs` のスキルがMCPのツールで行う。
- どのファイルを書き込んだかは、このフォルダの `.sync.json`（台帳）に残る。`tools/specs_sync.py` が管理する。
