# 予約のCSV出力

## 目的

予約の一覧を、表計算ソフトで開ける形で取り出したい。

## ふるまい

- `booking export --format csv` で、予約を標準出力へCSVで出す。
- 1行目は見出しで、列は `id`、`room`、`owner`、`start`、`end` の順。
- `start` と `end` は、東京時間のISO 8601（例 `2026-12-01T10:00:00+09:00`）。
- 並びは開始の早い順。同じ開始なら部屋の名前順。
- `--room` を付けると、その部屋だけを出す。
- 予約が1件もないときは、見出しの1行だけを出す。

## 完了の条件

- 上の6つのふるまいに、1つずつテストがある。
- `--format` に `csv` 以外を渡すと、終了コード1で理由を標準エラーに出す。
- 値にカンマや改行が入っていても、表計算ソフトで列がずれない。
- `make check` が通る。

## 扱わないこと

- ファイルへの書き出し（利用者がリダイレクトする）
- CSV以外の形式
