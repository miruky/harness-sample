# 予約の追加

## 目的

会議室を、時間を決めて押さえたい。

## ふるまい

- `booking add --room A --owner miruky --start 2026-12-01T10:00 --end 2026-12-01T11:00` で予約を1件作り、予約IDを標準出力へ出す。
- 開始と終了は15分単位。秒や、15分に合わない分は受け付けない。
- 1件の長さは4時間まで。ちょうど4時間は受け付ける。
- 開始が現在より前の予約は受け付けない。現在ちょうどは受け付ける。
- 同じ部屋で時間が重なる予約は受け付けない。終了と開始が接するだけなら重なりとしない。
- タイムゾーンのない時刻は、東京時間として扱う。

## 完了の条件

- 受け付けないときは終了コード1で終わり、理由を標準エラーに日本語で出す。
- 上のふるまいの、ちょうどの値と1つ外の値にテストがある。
- `make check` が通る。

## 扱わないこと

- 予約の変更（取り消して作り直す）
