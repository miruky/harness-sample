# 0002 現在時刻は Clock から受け取る

- 状態: 採用
- 日付: 2026-11-14

## 背景

「過去の時刻は予約できない」のように、現在時刻で結果が変わる決まりがある。コードの中で `datetime.now()` を呼ぶと、テストの結果が実行した日時で変わる。

## 決めたこと

domain の関数は `now: datetime` を引数で受け取る。service は `Clock` を受け取り `self._clock.now()` を使う。`datetime.now()` を呼んでよいのは `cli.py` の `SystemClock` だけにする。

## 結果

テストは `FixedClock` で時刻を固定でき、いつ、どのタイムゾーンで実行しても同じ結果になる。
