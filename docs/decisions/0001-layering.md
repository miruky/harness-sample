# 0001 層を4つに決め、内側から外側を import しない

- 状態: 採用
- 日付: 2026-11-14

## 背景

予約の重複判定や時間の決まりは、保存先がJSONでもデータベースでも変わらない。保存先や入口の都合が決まりごとの中へ入ると、テストのたびにファイルを用意することになる。

## 決めたこと

domain、service、storage、cli の4層に置き、import の向きを内側へ向かう一方向にする。service が保存先に求める形は Protocol で書く。

## 結果

domain と service のテストはメモリ上の保存先だけで動く。向きは `tools/check_layers.py` で検査する。
