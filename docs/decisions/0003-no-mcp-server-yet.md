# 0003 MCPサーバーは、まだ入れない

- 状態: 0004 で置き換え（Confluence とつなぐために、MCPサーバーを1つ入れた）
- 日付: 2026-11-14

## 背景

エージェントが外のサービスを使う方法には、MCPサーバーをつなぐ方法と、コマンドラインのツールを使わせる方法がある。
このリポジトリの作業で外のサービスに触れるのは GitHub だけで、`gh` で足りている。
MCPサーバーは入れておくだけでツールの説明がコンテキストに載り、サーバーのコードは手元の権限で動く。

## 決めたこと

MCPサーバーの設定（`.mcp.json`、`.codex/config.toml` の `mcp_servers`）は、いまは置かない。
次のどれかに当てはまったら、このファイルを置き換えて追加する。

- 使いたい外部サービスに、コマンドラインのツールがない
- ブラウザの操作など、コマンドでは結果を確かめられない作業が増えた

追加するときは、版を固定し、秘密の値は設定ファイルに書かず環境変数で渡す。

## 結果

エージェントが使える外部の入口は `gh` と `uv` だけになり、権限の設定とフックで見る範囲が小さくて済む。
