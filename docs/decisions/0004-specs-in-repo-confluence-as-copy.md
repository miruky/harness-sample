# 0004 仕様の正本はリポジトリ、Confluence は写し

- 状態: 採用
- 日付: 2026-11-14

## 背景

仕様を Confluence に置くと、エージェントは作業のたびに外へ取りに行くことになり、コードと仕様が別々に変わる。
リポジトリに置くと、開発者以外が見に来ない。

## 決めたこと

- 仕様は `docs/specs/` の Markdown を正本にする。コードと同じプルリクエストで変える。
- Confluence には `tools/docs_sync.py` が書き込む。push のたびにCIが実行し、プルリクエストでは一致を確かめる。
- 一致は、ページに書いた sha256 と、取得した本文の全文の2つで確かめる。画面で直接編集されたら、検査が落ちる。
- 書き込みを、エージェントのMCPのツール呼び出しには任せない。毎回必ず同じ結果になってほしい処理だから。
- MCPで Confluence につなぐなら、検索と参照に使う。つなぐときは `sandbox.network.allowedDomains` に接続先を足す。

## 結果

仕様を直して push すれば、レビューの指摘で直した分も含めて、Confluence が追いつく。
Confluence の画面で直した人は、次のプルリクエストの検査で気づく。
