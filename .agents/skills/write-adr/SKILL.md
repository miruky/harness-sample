# 設計の判断を残す

1. `docs/decisions/` の番号を確かめ、次の番号で `NNNN-短い名前.md` を作る。書式は `docs/decisions/0000-template.md` を写す。
2. 題名は決めたことを1文で書く。背景には、検討して選ばなかった案も1行ずつ残す。
3. 判断を機械で検査できるなら、どの検査が見るかを「結果」に書く。検査がまだなければ、足す提案を返答に書く。
4. 以前の判断を置き換えるときは、古いファイルの状態を「置き換え（→ 新しい番号）」に直す。古いファイルは消さない。
5. `docs/architecture.md` の説明が変わるなら、同じ変更の中で直す。
